## 当前工作：seqlist_sorted_insert.c

顺序表 + 输入时保持有序插入。先原样存档。

### 已知问题

编译层面（下面四条都会导致编译失败）：

1. `#define LIST_INIT_SIZE 20;` 宏定义末尾带了分号，展开后是 `malloc(sizeof(Elemtype)*20;)`，语法错误。`LISTINCREMENT 10;` 同理。
2. 结构体定义的类型名是 `Sqlist`，函数签名里写的是 `SqList`（大写 L、少一个 `s`），类型未定义。
3. `InitList(&L)`：`L` 本身已经是 `SqList *`，再取地址变成 `SqList **`，类型不匹配，应写 `InitList(L)`。
4. 缺 `#include <stdio.h>`（`scanf`）、`#include <stdlib.h>`（`malloc`）；`malloc` 返回值也未检查。

逻辑层面：

5. `break` 写在 `if` 外面：循环只比较第 0 个元素就跳出，"找到比 `temp` 大的位置"这件事根本没有发生，插入位置永远是错的。
6. 插入分支里已经执行过 `L->length++`，跳出后又会执行末尾的 `L->elem[L->length]=temp; L->length++;`，同一个元素被写两次、`length` 加两次。
7. 正确做法应是：找到第一个 `L->elem[j] > temp` 的下标 `j`，整体后移一位并插入；若循环走完都没找到，说明 `temp` 最大，直接追加到末尾（不需要两套代码）。
8. `LISTINCREMENT` 定义了却从未使用，`n > listsize`（默认 20）时 `L->elem[L->length]` 直接越界写。
9. 没有 `main`，也没有输出逻辑，单独编译无法验证结果。

### 后续计划

- 修宏分号、统一类型名 `SqList`、改 `InitList(L)`
- 重写 `CreatList`：单次定位 + 后移 + 插入，删除末尾的重复写入
- 加上扩容：`n > listsize` 时 `realloc` 到 `listsize + LISTINCREMENT`
- 补 `PrintList` 与 `main`，测试用例：递增输入、递减输入、含重复值、`n = 25`（触发扩容）

## 当前工作：circular_queue.c

同一文件里写了两版队列（一版非循环、一版循环），先原样存档，后续合并成一版完整的循环队列。

### 已知问题

编译层面：

1. `EnQueue` 在文件内被定义了两次（第 2 个函数与第 4 个函数），重定义会编译失败，需要保留一版、删掉另一版。
2. `DEQueue` 与 `DeQueue` 大小写不一致，在 C 里是两个不同函数名：第一版配套的是 `DEQueue`，第二版是 `DeQueue`，容易误调用。
3. 没有 `#include`、没有 `main`，单独编译无法运行。

逻辑层面：

4. 第二版 `Q->rear=(Q->rear+1)%5;` 写死成 5，应为 `%MAXSIZE`，否则容量超过 5 就开始错乱。
5. 第一版是非循环队列，判满用 `Q->rear>=MAXSIZE`，出队后 `front` 只增不减，会出现“假溢出”（尾部满了但前面还有空位）。
6. 两版都没有 `InitQueue`（应 `front = rear = 0`），未初始化的结构体直接使用会读到随机值。
7. 循环队列用 `(rear+1)%MAXSIZE == front` 判满，会牺牲一个存储单元，实际容量是 `MAXSIZE-1`，需要在注释里写清。
8. 出队时 `*x` 没有空指针检查；空队返回 0 时也没有修改 `*x`，调用方若不清零会读到垃圾值。

### 后续计划

- 合并为一版循环队列：`InitQueue` / `EnQueue` / `DeQueue` / `GetFront` / `IsEmpty` / `IsFull`
- 补 `main` 与测试用例：入队到满、连续出队、跨环回绕（`rear` 从 MAXSIZE-1 绕回 0）

## 当前工作：palindrome.c

回文判断（栈的应用）。先原样存档。

### 逻辑核对：正确

奇偶两条分支的边界都推演过，结果正确：

- 偶数 `n=4`（`abba`）：`temp=2`，压入 `a b`，从下标 2 开始比较 `b a`，返回 1。
- 奇数 `n=5`（`abcba`）：`temp=3`，压入前 `temp-1=2` 个字符 `a b`，从下标 3 开始比较 `b a`，正确跳过中间字符。

### 已知问题

编译层面：

1. `Push` / `Pop` 未定义，也没有 `#include`，单独编译无法通过。
2. 与 `expression_eval.c` 中的 `SqStack` 重复定义，两个文件不能直接一起编译（需要抽出公共头文件）。

逻辑层面：

3. 字符串长度超过 `MAXSIZE` 时没有保护，`Push` 返回 0 也没有检查，会越界写。
4. `Push` 的返回值全部被忽略，栈满时后续比较会读到脏数据。
5. 只用 `char` 比较，中文字符串（UTF-8 多字节）会被误判为回文/非回文。
6. 空字符串 `n=0` 走偶数分支直接返回 1，语义上可接受，但最好显式说明。

### 可优化点（考试可能追问）

7. 本题用栈是 O(n) 时间 + O(n) 空间；若允许不用栈，双指针从两端向中间夹逼可以做到 O(1) 空间，面试常拿这个做对比。
