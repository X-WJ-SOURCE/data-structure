### 已知问题

编译层面：

1. `EvaluatePostfix` 中 `else if(postfix[n]==' ')` 分支里是一句空的 `while()`，缺少循环条件，语法不完整。
2. `add` / `sub` / `mul` / `divi` 四个函数被调用但未定义。
3. `Push` / `Pop` 只在结构体上定义了数据，未给出函数声明与实现。
4. 使用了 `isalpha` / `isdigit`，但没有 `#include <ctype.h>`。

逻辑层面：

5. 中缀转后缀时数字是逐字符入输出的，`12+3` 会被拆成 `1 2 3 +`，多位数无法正确处理（应在数字后加分隔符或整体读取）。
6. 后缀求值里的 `isSpace==1` 分支意图是处理带空格分隔的多位数，而"多位数压栈"的核心逻辑还没写（当前 `while()` 处待补）。
7. `Push` 使用 `S.data` 数组随机访问来比较优先级，属于直接操作栈内数组，与 `Push`/`Pop` 的封装风格不一致，可改为提供 `GetTop` 接口。
8. 结尾没有对 `)` 不匹配、操作符连续等非法输入的完整校验。
9. `calc` 中除数为 0 未处理。
